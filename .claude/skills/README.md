# Skills

| Skill | What it covers |
|---|---|
| [`quran-data`](quran-data/SKILL.md) | **This corpus**: the sources, keys, text forms, morphology, the cleaning rules, the answer keys, the measured facts — read it before touching data, the connector or a signal |
| `curiosity-*` | The Curiosity platform, layer by layer: connector, graph modelling, workspace configuration, endpoints, similarity, AI tools, front end, delivery |

The `curiosity-*` skills are vendored from
[`curiosity-ai/application-template`](https://github.com/curiosity-ai/application-template)
(commit `6a49a24`, 2026-10-09). They refer to that template's reference implementation
(`sample-application/`); the examples apply here layer for layer. Update them by copying the
folders again — do not edit them in place; write what this repository learns into `quran-data`
or into CLAUDE.md instead.
